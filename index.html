Features

Everything a developer or DBA actually needs

Four workspaces in one sidebar — DBs, APIs, Git and Team — grouped by project, with the environment you're on always one click away.

Editor & data grid

Native performance

A single Rust binary built on egui — instant startup, a 30–70 MB memory footprint, fully async query execution on Tokio. No Chromium runtime dragging things down.

Modern SQL editor

Alias‑aware autocomplete, FK join suggestions, run‑statement‑at‑cursor (⌘+Enter), format, toggle comment, move/duplicate lines, go‑to‑line, find & replace with regex.

Safe by default

Grid saves run in one transaction and must hit exactly one row; UPDATE/DELETE without WHERE is flagged before it runs.

Filter builder & FK navigation

Build server‑side WHERE clauses from dropdowns, pin or freeze columns, and click a foreign‑key cell to jump to the parent row.

Charts from any result

Switch the result pane to bar, line, area or scatter, pick X/Y columns and an aggregate — no export needed.

Cell inspector

JSON tree, hex/binary view, image preview (PNG, JPEG, WebP, SVG) and virtual‑scrolling text for large cells.

Import, export & transfer

Open CSV, JSON, NDJSON or Excel files as queryable tables, import into any table, copy tables between connections, compare data, export as SQL/CSV/XLSX, or copy results as Markdown, JSON or INSERT statements.

Quick Open & command palette

⌘+P fuzzy‑searches tables, views, saved queries, history, connections and commands in one box.

Diagrams & understanding

ER diagrams with groups & notes

Pan‑and‑zoom entity‑relationship canvas generated from your schema. Group tables into domains, draw relations, add notes, and link a group to its git repository — the AI then suggests which tables belong to that code and shows the API endpoints that use them.

See it in the showcase

Query diagram

Right‑click any statement to see it as an animated data‑flow: sources → WHERE → GROUP BY → ORDER BY → result, with a step‑by‑step explanation and an "Analyze AI" button.

Visual query profiler

EXPLAIN ANALYZE rendered as a hierarchical node graph for PostgreSQL, MySQL and SQL Server — cost percentages, slow nodes in red, warnings for seq scans, cartesian products and disk spills.

APIs, Git & projects

Generate API endpoints from your Git repo New

Point an API folder at a repository and Tabular reads the code to create every endpoint as a ready‑to‑send request. Routes are detected without AI for Express, Fastify, NestJS, Next.js, FastAPI, Flask, Django, Laravel, Rails, Gin, Axum, Spring, ASP.NET and more; your AI agent then finds the ones the scanner missed and documents each one — params, headers, auth, body and response examples, status codes and the tables it reads or writes.

See it in the showcase

APIs linked to tables in the diagram New

An API folder and a diagram group that share a repository are linked automatically. Every generated endpoint is drawn on the ER canvas with lines to the tables it touches, so you can see which routes write to orders before you change it — and jump from a table to its endpoints or from an endpoint to the diagram group in one click.

See it in the showcase

Built‑in HTTP client

REST collections next to your SQL tabs — JSON, form, multipart, GraphQL, XML bodies; Bearer/Basic/API‑key auth; paste a curl command to import; export code; Postman & Yaak import.

Git client & merge review

Status, commits and branches for the repositories behind your APIs and diagrams, plus AI‑assisted review of GitHub pull requests and GitLab merge requests.

Projects & environments

A project bundles connections, saved queries and an HTTP collection, with .env‑style Development / Staging / Production variables and an AI memory per project. Projects, diagram groups and API folders can all share one repository.

AI & Agents

Your schema, your model, your rules

Tabular talks to the AI you already pay for — and lets your coding agents talk to your databases without ever seeing a password.

AI Assistant ⌘+Shift+A

Schema‑aware chat docked beside the editor: explain, optimize or review a query, or let the agent write SQL straight into a tab with live edit and one‑click revert. Bring your own key — OpenAI, Anthropic Claude, Google Gemini, xAI, Groq, OpenRouter, GitHub Models, or local Ollama / llama.cpp / MLX — or run CLI agents such as Claude Code, Gemini CLI and Antigravity side by side.

MCP server for coding agents

tabular mcp lets Claude Code, Cursor, Codex and any MCP client list connections, describe schemas, run read‑only queries and get EXPLAIN plans. Credentials never leave Tabular; writes need your approval; every agent query is audited.

WebAssembly plugins

Sandboxed wasmi runtime with host APIs. Starter plugins export Parquet & DuckDB and generate ORM models for Diesel, SeaORM, Prisma, TypeORM and SQLAlchemy.

DBA Tools

Operate the database, not just query it

Right‑click a database in the tree and everything a DBA reaches for is already there.

Live process monitor

Real‑time processlist, deadlock & lock tree, a metrics dashboard (queries/s, connections, buffer cache hit) and the slowest statements — with one‑click cancel or kill.

Backup & restore wizard

Native pg_dump, mysqldump, SQLite, MongoDB and SQL Server backups with streaming logs and .sql.gz / .tar / .dump output. Restore from the same dialog.

Schema diff & migrations

Compare two schemas structurally and generate forward ALTER TABLE scripts and their rollback. Copy, rename or transfer whole databases between servers.

Users & privileges GUI

Create accounts, change passwords and manage grant matrices per database and table without memorising GRANT syntax.

SSH, bastions & mTLS

Multi‑hop SSH jump hosts, passphrase‑protected keys, custom CA and client certificates — managed automatically per connection.

Redis & MongoDB browsers

Visual key explorer with type filters, TTL and memory size for Redis (standalone or cluster); collections, documents and compression for MongoDB.

Cloud & Security

We designed cloud sync so we can't read your data.

Tabular Server (Rust + Axum + MySQL) syncs connections, queries, HTTP collections and diagrams across your devices and teams — without ever seeing inside them.

1. Encrypt on your device

Secrets are encrypted locally with AES‑256‑GCM under a key derived with Argon2id before anything is sent.

2. Only ciphertext travels

The wire and the database both only ever see an opaque encrypted blob.

3. Share with X25519 sealed boxes

Team vaults re‑wrap keys for each member with public‑key crypto — owner, editor and viewer roles, no plaintext on the server.

AES‑256‑GCM + Argon2id X25519 team vaults OAuth2 (Google, GitHub) + JWT rotation OS keychain for credentials Realtime collab via CRDTs No telemetry by default
